## Reporting a Vulnerability

We take the security of `trace-lite` seriously. If you discover a security vulnerability, please report it responsibly instead of opening a public GitHub issue.

### How to Report

1. Send an email describing the vulnerability to the project maintainers or open a private draft security advisory on GitHub.
2. Include full details of the vulnerability:
   - Affected component (Core SDK, CLI, Web UI, or Obsidian plugin)
   - Step-by-step instructions to reproduce the issue
   - Any potential impact or proof of concept

### What to Expect

- **Acknowledgment**: We will acknowledge your report within 48 hours.
- **Assessment**: We will assess the issue and provide an estimated timeline for a fix.
- **Fix & Disclosure**: Once resolved, a patch release will be published and credit will be awarded in the release notes.
